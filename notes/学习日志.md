### 实际完成（按顺序）

1. **确认工具链**
   - Git：`git version 2.56.0.windows.3`（`C:\Program Files\Git\cmd\git.exe`）
   - Python：`3.12.10`（`%LOCALAPPDATA%\Programs\Python\Python312\python.exe`）
   - 机器上还有 Python 3.14，`python` 命令默认指向它——**没有用它建环境**，避免 torch 缺少 3.14 的 Windows wheel。

2. **修复 Git 的 PATH**
   - 现象：`git --version` 报"无法将 git 项识别为 cmdlet…"。
   - 排查：`Test-Path 'C:\Program Files\Git\cmd\git.exe'` 为 `True`，但该目录不在用户 PATH 里。
   - 处理：用 `fix_path.ps1` 把 `C:\Program Files\Git\cmd` **永久追加到用户 PATH**（幂等、不动系统 PATH），重开终端后生效。

3. **配置 git 身份**

   ```powershell
   git config --global user.name "YangLv1123"
   git config --global user.email "<GitHub 绑定邮箱>"
   git config --global init.defaultBranch main
   ```

4. **创建 GitHub 空仓库**
   - `learning-journal`，Private，三个初始化勾全部不勾（保持空仓库）。

5. **克隆到本地**

   ```powershell
   cd $HOME
   git clone https://github.com/YangLv1123/learning-journal.git
   ```

   出现 `warning: You appear to have cloned an empty repository.`（正常）。

6. **创建虚拟环境**
   - 用 Python 3.12 显式创建：

   ```powershell
   & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv .venv
   ```

   - 激活时被 PowerShell 执行策略拦截（`SecurityError: 禁止运行脚本`），解决：

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   .venv\Scripts\Activate.ps1
   ```

7. **安装依赖**（venv 内，最终版本）

   | 包 | 版本 |
   |---|---|
   | numpy | 2.5.4 |
   | pandas | 3.1.0 |

   | torch | 2.14.1+cpu |
   | matplotlib | 3.11.2 |

8. **计划文档入库 + 首次推送**

   - 首次 push 弹浏览器完成 GitHub 认证；
   - 结果：`* [new branch] main -> main`，commit `e32497a`。

9. **环境自检**
   - 运行 `check_env.ps1`，13 项全部 `[OK]`，结论 `ALL PASS - ready for D2`。

### 遇到的问题与解决

| 问题 | 现象 | 原因 | 解决 |
|---|---|---|---|
| git 命令找不到 | `无法将"git"项识别为 cmdlet…` | Git 目录不在用户 PATH | 永久追加 `C:\Program Files\Git\cmd` 到用户 PATH，重开终端 |
| 激活 venv 被拒 | `SecurityError: 禁止运行脚本` | PowerShell 执行策略默认 Restricted | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| push 连接被重置 | `Recv failure: Connection was reset` / `Failed to connect …:443` | VPN 关闭后系统代理 `127.0.0.1:7892` 变成死端口，GitHub 直连被墙 | 重新打开 VPN（系统代理/全局），push 成功 |
| python 版本不对 | `python` 指向 3.14 | PATH 中有多个 Python | 建 venv 时显式用 3.12 的绝对路径 |
