# 08 · 常见报错速查（D1–D6 环境期用）

> 用法：遇到报错先看"现象"列对号入座；没有的就按 `06-每日日志模板.md` 底部的求助格式发我。
> 通用心法：Python 报错**从最后一行往上看**——最后一行是真正的错误类型，往上找"你自己写的文件的那一行"。

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | `winget` 不是内部或外部命令 | Win10 旧版本没有 winget | 走官网下载安装包：python.org/downloads（**勾选 Add to PATH**）、git-scm.com、code.visualstudio.com |
| 2 | `python` 不是内部或外部命令 | 装 Python 时没勾 Add to PATH | 重装勾选；或把 `C:\Users\你\AppData\Local\Programs\Python\Python312\` 和 `...\Scripts\` 加进系统 PATH 后**新开窗口**再试 |
| 3 | `python --version` 不是 3.12 | 装了别的版本 | ≥3.10 都能继续，不用折腾；venv 以你实际用的那个 python 为准 |
| 4 | 激活 venv 报"禁止运行脚本" | PowerShell 执行策略限制（默认 Restricted） | 永久：`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`；临时：`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`；都不想改就直接用 `.\.venv\Scripts\python.exe -m pytest`，不激活也能跑 |
| 5 | pip 装包极慢/超时 | 默认源在国外 | 换清华镜像：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` |
| 6 | `pytest` 不是内部或外部命令 | 没激活 venv（提示符前应有 `(.venv)`）或没装 | 先 `.venv\Scripts\Activate.ps1`，再 `pip install pytest` |
| 7 | git push 反复要密码/失败 | HTTPS 认证没配好 | 换 SSH：`ssh-keygen -t ed25519` 一路回车 → `Get-Content $HOME\.ssh\id_ed25519.pub` 复制 → GitHub Settings → SSH and GPG keys → New SSH key → 用 `git@github.com:...` 地址 clone |
| 8 | 忘了 commit 顺序 | — | 永远三步：`git add .` → `git commit -m "Dxx: ..."` → `git push`；随时 `git status` 看状态（红=未暂存，绿=已暂存） |
| 9 | commit 报"please tell me who you are" | 没配 git 身份 | 执行 README 里的两条 `git config --global user.name/email` |
| 10 | 读/写文件报 `UnicodeDecodeError: 'gbk' codec...` | Windows 默认用 gbk 解码 | 打开文件时显式写 `open(..., encoding="utf-8")`，写文件同理 |
| 11 | `ModuleNotFoundError: numpy` | 在错误的 Python 环境里跑 | 确认提示符有 `(.venv)`；或用 `python -m pytest` 而不是裸 `pytest` |
| 12 | torch import 报 OSError / DLL 错误 | CPU/CUDA 版本装错 | 无 GPU 一律按 README 用 `--index-url https://download.pytorch.org/whl/cpu` 装，别裸 `pip install torch` |
| 13 | VS Code 里跑不通、PowerShell 正常 | VS Code 选了错误的解释器 | 右下角点 Python 版本号 → 选择 `.venv\Scripts\python.exe` |
| 14 | 不知道自己现在在哪个目录 | — | `Get-Location`；进入目录用 `cd 路径` |
| 15 | 命令卡住不动 | pip 慢或程序死循环 | Ctrl+C 中断；先贴报错给我，别急着重启电脑 |
| 16 | 报错一大串看不懂 | 正常 | 只读最后一行（错误类型）+ 你写的文件那一行；两行都贴给我 |
| 17 | `pip install torch` 报 "Could not find a version" 或卡在 building wheel | Python 版本太新（如 3.14），还没有预编译 wheel | 用 3.12 建 venv：`& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv .venv`，激活后再装 |
| 18 | 第一次 `git push` 弹浏览器或要求登录 | 正常：Git Credential Manager 首次认证 | 浏览器登录 GitHub 并授权；没弹窗就 `git config --global credential.helper manager` 后重试。GitHub 早已不支持密码推送，别输账号密码 |

## 专题：装完仍提示"无法将 XX 项识别为 cmdlet、函数…"

这是 Windows 上最高频的问题：**安装程序改了 PATH，但已经打开的终端不会自动刷新**。

**第一步：判断到底装没装**（在 PowerShell 里跑）：

```powershell
Test-Path 'C:\Program Files\Git\cmd\git.exe'                       # git
Test-Path "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" # python（按用户安装）
py --version                                                       # python 启动器（如果装了）
```

**第二步：按结果分支**

| 结果 | 含义 | 处理 |
|---|---|---|
| `True` | 装了，PATH 没生效 | 关掉所有 PowerShell 窗口重开；急用可临时 `$env:Path = 'C:\Program Files\Git\cmd;' + $env:Path` |
| `False` | 没装上 | `winget install --id Git.Git -e --source winget`（Python 同理 `--id Python.Python.3.12`），看到"已成功安装"后**重开窗口** |

**第三步：验证**

```powershell
git --version
python --version
```

**彻底解决（永久加入用户 PATH，适用于 Test-Path 为 True 但重开窗口仍无效）**

说明：如果目录根本不在 PATH 里，重开窗口是没用的，必须写进去。

```powershell
# 方式一：脚本（幂等，只追加一条，不动系统 PATH）
powershell -ExecutionPolicy Bypass -File .\fix_path.ps1
# 默认追加 C:\Program Files\Git\cmd；别的目录用 -Dir 指定

# 方式二：图形界面
# Win+R → sysdm.cpl → 高级 → 环境变量 → 用户变量 Path → 编辑 → 新建 → 粘贴目录 → 全部确定
```

写入后**必须关掉所有终端和 VS Code，从开始菜单重新打开**（PATH 在进程启动时继承，旧进程不会更新）。

**千万不要**用 `setx PATH "%PATH%;..."`——它会把系统+用户 PATH 合并并截断到 1024 字符，可能直接弄坏 PATH。

**记住一条规则**：任何 winget / 安装包装完之后，**旧窗口一律作废**，重开再试。
