# 学习资源清单（按计划周索引，每类只留精华，别收藏不看）

> 原则：**每个资源绑定到 60 天计划的某一天**；看完立刻有产出（笔记/代码），否则不看下一个。

## W1 用（Python / 数学 / PyTorch）

- Python 教程：廖雪峰 <https://liaoxuefeng.com/>（D2–D3 按需查）；官方教程 <https://docs.python.org/3/tutorial/>
- numpy 快速入门：<https://numpy.org/doc/stable/user/quickstart.html>（D4）
- pandas 10 分钟入门：<https://pandas.pydata.org/docs/user_guide/10min.html>（D5）
- 数学直觉：3Blue1Brown 线代系列 <https://www.3blue1brown.com/topics/linear-algebra>（D6，只看前 4 集）
- PyTorch 官方入门（60 分钟 blitz）：<https://pytorch.org/tutorials/beginner/basics/intro.html>（D6）
- pytest 官方：<https://docs.pytest.org/>（D3 起每天用）

## W2 用（ML 基础）

- 吴恩达《Machine Learning Specialization》（前两门即可）：<https://www.coursera.org/specializations/machine-learning-introduction>（D8–D9）
- 指标速查：scikit-learn 的 [Metrics 页面](https://scikit-learn.org/stable/modules/model_evaluation.html)（D9）
