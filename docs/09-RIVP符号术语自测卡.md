## 2. 角色与关系清单（背到不假思索）

**六个查询角色**：`incident.entry` / `service.caller` / `service.callee` / `deployment.runtime` / `host.node` / `config.version`

**三个观测角色**：`signal.trace` / `signal.metric` / `signal.log`

**四个关系**：`includes` / `calls` / `runs_on` / `observes`

**三态**：support（时间窗内、与候选关联的确认记录）/ contradict（明确反对的记录）/ unknown（缺失、迟到、无关联——空结果 ≠ 否定）

**状态机**：verified（支持）/ uncertain（矛盾或未知，保留排序但不断言）/ failed（建不出候选范围）

## 3. 自测方式（D7 / D13 / D52 各跑一遍）

1. 遮住含义列，口头解释每个符号，卡壳的做标记；
2. 只看"六查询角色+四关系"，画出一条论文示例的 role path；
3. 对 Eq.1、Eq.2、Eq.5 三个公式，各写一句人话解释。
