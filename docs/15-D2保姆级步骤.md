## 3. 写 `word_count.py`（提示，不是答案）

思路四步：

1. 把整段文本转小写；
2. 把文本切成"单词列表"——只保留字母和数字，标点当分隔符；
3. 用 dict 数每个单词出现几次；
4. 返回这个 dict。

> 提示：正则 `re.findall(r"[a-zA-Z0-9]+", text.lower())` 能一步完成第 1、2 步。**先弄懂它为什么能去掉标点**，再写进代码。`re` 需要 `import re`。

写不出就先只做第 2 步，`print` 出来看对不对，再往下。

## 4. 写 `csv_io.py`（提示，不是答案）

四步：

1. `csv.DictReader` 逐行读入，每行是一个 dict；
2. 按 `row["user"]` 聚合：出现次数 +1，金额累加；
3. `sorted()` 按 user 排序；
4. `csv.writer` 先写表头，再逐行写。

> 坑 1：`DictReader` 读出来的值**全是字符串**，金额相加前要 `int(row["amount"])`，否则会变成 `"25"` 这种字符串拼接。
> 坑 2：写文件用 `open(path, "w", newline="", encoding="utf-8")`，`newline=""` 防止 Windows 下多出空行。

## 7. 常见错误对照

| 报错/现象 | 原因 | 解决 |
|---|---|---|
| `IndentationError` | 缩进不一致（空格/Tab 混用） | 统一 4 个空格 |
| `NameError: name 're' is not defined` | 忘了 `import re` | 文件顶部加 `import re` |
| 测试失败但没报错，显示 `None != {...}` | 函数忘了 `return` | 检查每个函数最后有没有 return |
| `"7.0" != "7"` | 金额被当成浮点或字符串 | 用 `int(row["amount"])` |
| `"Hello"` 和 `"hello"` 各算一次 | 忘了转小写 | 先 `text.lower()` |
| 测试找不到 | 不在练习目录里跑 | `cd` 到 `d2_word_count` 再跑 |
