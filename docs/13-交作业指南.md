## 每日标准流程（以 D2 为例，之后每天照抄，只换包名）

```powershell
# 1) 把当天的练习包复制到学习仓库（本地留着原版，别直接改原版）
cd C:\Users\32720\Desktop\GitHub\learning-journal   # 换成你实际 clone 的位置
mkdir code\d2_word_count
Copy-Item 'C:\Users\32720\Desktop\实习项目学习\exercises\d2_word_count\*' code\d2_word_count -Recurse

# 2) 在复制出来的副本里做题
cd code\d2_word_count
python -m pytest -v        # 红灯：预期失败
# ... 补全 word_count.py、csv_io.py ...
python -m pytest -v        # 绿灯：全过才算完

# 3) 回到仓库根目录提交
cd C:\Users\32720\Desktop\GitHub\learning-journal
git status                 # 确认改动只有 code/d2_word_count 下的 .py
git add .
git commit -m "D02: word_count + csv_io 全绿"
git push
```

## 必须熟练的 4 条 git 命令

1. `git status` —— 看改了什么（**每次提交前必看**）
2. `git add .` —— 暂存全部改动
3. `git commit -m "Dxx: 说明"` —— 提交
4. `git push` —— 推到 GitHub

push 报认证错误 → [08-常见报错速查.md](C:\Users\32720\Desktop\实习项目学习\08-常见报错速查.md) 第 7 条。

## 新手 90% 栽的三个坑

1. **把垃圾文件提交上去**：`__pycache__/`、`.pytest_cache/`、`.venv/` 千万别提交——用下面的 .gitignore。
2. **在错误的目录里 git add**：提交前先确认自己在仓库根目录（`Get-Location`），否则可能把整个桌面加进去。
3. **红着就提交**：测试没绿 = 作业没完成。先绿灯，再 commit。

## .gitignore 模板（复制进每个仓库根目录）

```gitignore
__pycache__/
.pytest_cache/
.venv/
*.pyc
.ipynb_checkpoints/
```
